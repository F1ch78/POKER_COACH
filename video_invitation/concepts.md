# Видео-приглашение «Вечеринка без повода»: концепции

## Бриф (по итогам опроса)

| Параметр | Значение |
|---|---|
| Мероприятие | Частная вечеринка без повода |
| Тон | Юмор, ирония |
| Формат | Вертикаль 9:16, до 60 с (целимся в 40–50 с: дольше в мессенджере не досматривают) |
| Продакшн | Без съёмок: моушн-графика + ИИ-генерация видео |
| Материалы | Фото героя праздника, голос за кадром |
| Обязательный финал | Имя хозяина, дата, время, место, дресс-код (если есть), кнопка/просьба ответить |

**Общая драматургия для всех вариантов.** Крючок в первые 2 секунды, чтобы не пролистали.
Шутка нарастает. Перелом: «а повод-то и не нужен». Финальная плашка с деталями держится
не меньше 5 секунд, чтобы её успели прочитать или сделать скриншот.

---

## 1. «БЕЗ ПОВОДА». Трейлер блокбастера

**Логлайн.** Пафосный голливудский трейлер о человеке, который решился на немыслимое:
устроить вечеринку без единой причины.

**Почему работает.** Пародию на трейлер узнают все. Контраст эпической подачи и бытового
содержания смешит сам по себе. Герой на фото превращается в «звезду фильма», и ему это льстит.

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–3 с | Чёрный экран, гул, логотип студии «ПРОСТО ТАК PICTURES» | *(трейлерный бас)* «В мире, где для праздника нужен повод…» |
| 3–10 с | ИИ: герой (по фото) смотрит в окно под дождём, листает пустой календарь | «…один человек сказал: хватит». |
| 10–20 с | Нарезка: герой в замедленной съёмке несёт пакеты с чипсами; взрыв конфетти за спиной; герой надевает солнечные очки | «Ни дня рождения. Ни Нового года. Ни пятницы». |
| 20–30 с | Плашки с отзывами: «★★★★★ Лучшая вечеринка, на которую я ещё не ходил». *— Сосед*; «Он сошёл с ума». *— Мама* | Барабаны |
| 30–38 с | Склейка-удар, тишина, герой в камеру | *(обычным голосом героя)* «Ну а чё нет-то?» |
| 38–48 с | Титр в стиле постера: «БЕЗ ПОВОДА. Только в одном доме. Только один вечер» + дата, место | «В главной роли — ты. Если придёшь». |

**Визуал.** Тёмная teal-and-orange палитра, широкие кинорамки поверх вертикали, крупный
серифный титр, плёночное зерно.
**Голос.** Трейлерный бас (ИИ-озвучка) + одна живая фраза героя.
**Сложность.** Средняя: 4–5 ИИ-шотов с героем.
**Риск.** Жанр популярный. Спасают конкретные локальные шутки в отзывах (впишите имена друзей).

## 2. «ЧРЕЗВЫЧАЙНЫЕ НОВОСТИ». Экстренный выпуск

**Логлайн.** Федеральный канал прерывает эфир: в городе зафиксирована вечеринка без
официального повода. Эксперты в замешательстве.

**Почему работает.** Новостная графика (бегущая строка, «МОЛНИЯ», включения) даёт много
мест для мелких шуток. Гости ставят на паузу, чтобы дочитать бегущую строку, и смотрят ролик дважды.

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–3 с | Заставка «МОЛНИЯ», красный экран, сирена-джингл | «Срочное сообщение!» |
| 3–12 с | ИИ-ведущая в студии, за ней фото героя с подписью «ОРГАНИЗАТОР» | «Сегодня стало известно: [Имя] планирует вечеринку. Повода нет». |
| 12–22 с | Включение «с места событий»: ИИ-корреспондент у подъезда; бегущая строка: «ЗАПАСЫ ЧИПСОВ В МАГАЗИНАХ ИСТОЩЕНЫ • СОСЕДИ ЗАКУПАЮТ БЕРУШИ • ПОВОД ТАК И НЕ НАЙДЕН» | «Очевидцы говорят: он просто захотел». |
| 22–32 с | «Эксперт» в окошке (ИИ-профессор): «За 40 лет практики я такого не видел» | |
| 32–40 с | Прогноз погоды: карта города, над адресом вечеринки иконка «🎉 +100% к настроению, местами танцы» | «Синоптики предупреждают…» |
| 40–50 с | Финальная новостная плашка: дата, время, адрес; «Следите за развитием событий лично» | «Оставайтесь с нами. Точнее, приходите». |

**Визуал.** Узнаваемый новостной дизайн (без логотипов реальных каналов): синий и красный,
плашки, бегущая строка.
**Голос.** Дикторский, серьёзный; комизм в контрасте.
**Сложность.** Средняя. Графика простая, ИИ нужен для ведущей и корреспондента.
**Риск.** Минимальный, формат легко масштабировать.

## 3. «ПОВОД НЕ НАЙДЕН». ИИ ищет причину и сходит с ума

**Логлайн.** Умный помощник пытается найти повод для вечеринки, перебирает всё более
абсурдные причины и ломается.

**Почему работает.** Абсурд нарастает с каждым шагом. Интерфейс в вертикальном ролике
смотрится естественно, как запись экрана телефона. Финал с моралью: «Повод — это вы».

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–4 с | Экран телефона, строка поиска, печатается: «повод для вечеринки» | Звук клавиатуры |
| 4–8 с | Загрузка… «Ошибка 404: повод не найден» | *(голос ассистента)* «Повод не обнаружен». |
| 8–25 с | Ассистент «предлагает варианты», каждый сопровождается ИИ-клипом с героем: «День рождения кактуса?» (герой поздравляет кактус) • «Годовщина покупки чайника?» (герой обнимает чайник) • «Вторник?» (герой в костюме вторника) | Голос ассистента всё больше «глючит» |
| 25–33 с | Глитч, экран рассыпается, ассистент «перегревается»: «Я… не… понимаю… людей…» | Искажённый голос |
| 33–40 с | Тишина, чистый экран, печатается: «повод — это вы» | *(голос героя)* «Короче, просто приходите». |
| 40–50 с | Карточка-приглашение в стиле уведомления: «Новое событие от [Имя]» + детали + «Принять / Принять» (обе кнопки «Принять») | |

**Визуал.** UI в духе iOS/Android, чистая типографика; ИИ-клипы открываются внутри
«карточек результатов».
**Голос.** Синтетический голос ассистента + живая фраза героя.
**Сложность.** Средняя: 3–4 абсурдных ИИ-шота, остальное графика.
**Изюминка.** Гости потом сами шутят «повод не найден». Готовый мем для вечеринки.

## 4. «В МИРЕ ЖИВОТНЫХ». Документальный фильм о дикой природе

**Логлайн.** Неторопливый закадровый голос натуралиста рассказывает о редком виде,
хозяине вечеринки, в естественной среде обитания перед брачным… то есть праздничным сезоном.

**Почему работает.** Интонацию документалок о природе мгновенно узнают и любят.
Бытовые действия в «научной» подаче смешат без грубостей. Мягкий юмор подходит любой компании.

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–5 с | ИИ: рассвет над саванной, плавный пролёт дрона… камера «залетает» в окно квартиры | Этническая музыка. «Африка. Нет. Это [город]». |
| 5–15 с | Герой (по фото) крадётся по супермаркету с тележкой, снято «длиннофокусником» из-за стеллажа | *(шёпотом)* «Перед нами редкий экземпляр — [Имя] обыкновенный. В этот период он запасает чипсы». |
| 15–25 с | Герой расставляет стулья, развешивает гирлянду | «Самец строит гнездо. Повода у него нет. Инстинкт сильнее». |
| 25–35 с | Анимация: точки на карте города (гости) стягиваются к одному дому | «Скоро начнётся великая миграция. Стаи потянутся к водопою». |
| 35–42 с | Герой замирает и смотрит прямо в камеру | «Тихо… кажется, он нас заметил». |
| 42–52 с | Финальная карточка в стиле научной таблички: «Место обитания: [адрес]. Сезон активности: [дата, время]» | «Не пропустите это зрелище». |

**Визуал.** Природные цвета, титры-таблички, эффект телеобъектива и тряски.
**Голос.** Голос натуралиста, спокойный и бархатный (ИИ-озвучка или ваш голос с правильной интонацией).
**Сложность.** Средняя и выше: нужно 4–5 ИИ-шотов героя в разных бытовых сценах.
**Риск.** Важна именно интонация голоса, без неё шутка не работает.

## 5. «ЧАТ ВЫШЕЛ ИЗ-ПОД КОНТРОЛЯ». Переписка в реальном времени

**Логлайн.** Герой осторожно пишет в общий чат «может, соберёмся?», а чат превращается
в лавину голосовых, стикеров, опросов и паники. Вечеринка организуется сама.

**Почему работает.** Это жизнь каждого: узнаваемые типажи из чата (тот, кто всегда «я
пас», тот, кто шлёт 10 стикеров). Самый дешёвый вариант: почти чистая моушн-графика.

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–4 с | Интерфейс мессенджера, чат «Друзья 🍕». Герой печатает… стирает… печатает: «может, соберёмся?» | Звук печати |
| 4–15 с | Ответы ускоряются: «а повод?», «повод??», «ты болеешь?», «кто ты и что сделал с [Имя]» | Звуки уведомлений учащаются |
| 15–25 с | Лавина: голосовые сообщения (ИИ-голоса, короткие абсурдные реплики), стикеры с лицом героя (ИИ из фото), опрос «Повод: а) нет б) нет в) нет» с результатом 100% | Нарастающий ритм |
| 25–33 с | Экран переполняется, сообщения летят сплошной стеной, телефон «вибрирует» | Пик хаоса |
| 33–40 с | Всё обрывается. Одно сообщение от героя: голосовое 0:03 | *(голос героя)* «Короче, в субботу у меня». |
| 40–50 с | Сообщение закрепляется: «📌 [Дата, время, адрес]». Последний ответ: «я пас… шучу, иду» | |

**Визуал.** Узнаваемый, но обобщённый мессенджер (без логотипов), аватарки-иллюстрации,
стикеры-мемы с героем.
**Голос.** Голосовые сообщения разными голосами + финальная фраза героя.
**Сложность.** Низкая: ИИ только для стикеров с лицом героя.
**Бонус.** Можно вписать реальные имена друзей в чат. Персонализация без доплаты.

| 1. Трейлер | ★★★ | ★★ | ★★ | ★★★ | ★★ |
| 2. Новости | ★★★ | ★★★ | ★★★ (бегущая строка) | ★★ | ★★ |
| 3. Повод не найден | ★★ | ★★★ | ★★ | ★★ | ★★ |
| 4. В мире животных | ★★★ | ★★★ | ★★ | ★★★ | ★★ |

**Рекомендация режиссёра:** вариант 3 («Повод не найден»). Он сам обыгрывает идею
«вечеринки без повода», финал даёт тёплую мораль, а «повод не найден» становится
внутренней шуткой праздника (можно повторить на табличках, торте, футболках).
Бюджетная альтернатива: вариант 5 («Чат»).

Варианты можно смешать: например, ИИ-ассистент из №3 в финале №5.

## Вторая волна: варианты с необычным заходом

Главное в этих вариантах — первые 1–3 секунды. Зритель должен решить, что это не реклама и не
очередное видео, а что-то, что происходит лично с ним. Каждый крючок ломает привычный сценарий
просмотра: имитирует интерфейс телефона, «ломает» видео или обращается прямо к зрителю.

## 6. «ВХОДЯЩИЙ ВИДЕОЗВОНОК»

**Крючок (0–3 с).** Видео начинается как настоящий входящий звонок: полноэкранный интерфейс,
фото героя, имя, вибрация, рингтон, кнопки «Принять / Отклонить». Палец сам тянется нажать.
Через секунду «звонок принимается» сам.

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–3 с | Интерфейс входящего вызова, пульсирующий аватар героя | Рингтон, вибрация |
| 3–6 с | «Соединение…», картинка дёргается, ИИ-герой слишком близко к камере, смотрит снизу, как все наши родители | «Алло? Меня видно? Нажми там что-нибудь». |
| 6–20 с | Герой отходит, за ним хаос подготовки (гирлянды, шары падают) | «Короче, у меня вечеринка. Повод? Не, нету. Просто приходи». |
| 20–30 с | Связь «зависает» на смешной гримасе героя, пиксели | «…ты меня слышишь? Алло?» |
| 30–40 с | Герой пишет в чат звонка детали (появляются текстом поверх) | «Короче, всё в чате». |
| 40–48 с | «Звонок завершён · 0:42». Карточка с датой и адресом, кнопка «Перезвонить = я приду» | |

**Почему цепляет.** Обман ожиданий за 0 секунд: человек думает, что ему реально звонят.
**Сложность.** Низкая-средняя: 2–3 ИИ-шота «говорящей головы» по фото.

## 7. «ВИДЕО СЛОМАЛОСЬ»

**Крючок (0–3 с).** Ролик начинается с ошибки: серый экран, крутится загрузка, «Видео недоступно».
Зритель уже готов листать дальше, и тут из-за края экрана высовывается рука героя и стучит по «стеклу».

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–2 с | Бесконечная загрузка, «Видео недоступно в вашем регионе» | Тишина |
| 2–6 с | Экран трескается изнутри, сквозь трещину заглядывает герой | «Стоп-стоп, не листай! Сейчас починю». |
| 6–15 с | Герой «чинит» видео: перетаскивает пиксели, заклеивает трещину скотчем, бьёт по интерфейсу | Звуки возни, «так… это не туда…» |
| 15–30 с | Видео «включается», но не то: реклама пылесоса, котики, прогноз погоды; герой их выбрасывает из кадра | «Не то… не то… о, вот!» |
| 30–40 с | Наконец «правильное видео»: конфетти, герой в праздничном колпаке | «Вечеринка. Без повода. Ты приглашён». |
| 40–48 с | Детали на карточке; в углу снова мелькает «ошибка» — герой её прихлопывает | |

**Почему цепляет.** Ломает четвёртую стену. Первая реакция зрителя: «что с телефоном?»
**Сложность.** Средняя: ИИ-шоты героя на зелёном фоне + моушн-графика интерфейса.

---

## 8. «НАВЕРНОЕ, ВАМ ИНТЕРЕСНО, КАК Я СЮДА ПОПАЛ»

**Крючок (0–3 с).** Стоп-кадр в самом конце вечеринки: 5 утра, герой в ростовом костюме
динозавра спит в ванне с конфетти, вокруг гирлянды и коробки пиццы. Запись пластинки.
Голос героя: «Да, это я. Наверное, вам интересно, как я сюда попал».

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–4 с | Стоп-кадр хаоса, звук скрэтча | «Да, это я. Наверное, вам интересно…» |
| 4–8 с | Перемотка назад на быстрой скорости, титр «12 часов назад» | Звук перемотки кассеты |
| 8–25 с | Герой в обычный день: смотрит на календарь — повода нет. Цепочка решений с плашками: «Решение №1: позвать пару друзей». «Решение №2: позвать ВСЕХ». «Решение №3: костюм динозавра» | Голос героя комментирует, как в фильме |
| 25–35 с | Быстрая нарезка подготовки, гости-силуэты стягиваются | «И вот тут всё пошло… прекрасно». |
| 35–40 с | Снова стоп-кадр из начала | «Хочешь узнать, что было между?» |
| 40–50 с | Карточка: «Узнай лично» + дата и место | «Приходи». |

**Почему цепляет.** Начинаем с кульминации: зрителю нужно узнать, «что случилось». Узнаваемый мем.
**Сложность.** Средняя: 3–4 ИИ-шота. Шот с динозавром в ванне — главный, на него уйдёт больше попыток.

## 9. «НЕ ЛИСТАЙ»

**Крючок (0–2 с).** Герой смотрит прямо в камеру и шёпотом: «Не листай. Да, ты. Убери палец».
Когда зритель всё-таки может провести пальцем, герой «держит» экран руками, будто ролик пытаются
пролистнуть: картинка уезжает вверх, он её подтягивает обратно.

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–3 с | Крупный план героя, палец у губ | «Тссс. Не листай. Да, ты». |
| 3–8 с | Картинка дёргается вверх (имитация свайпа), герой хватается за край кадра и тянет обратно | «Я сказал не листай!» |
| 8–20 с | Герой зажимает экран коленом, держит одной рукой и параллельно показывает табличку «ВЕЧЕРИНКА» | «Это займёт 30 секунд. У меня вечеринка». |
| 20–30 с | Внизу «подглядывают» следующие видео в ленте (котик, рецепт), герой их отпихивает | «Котик подождёт». |
| 30–40 с | Герой устаёт, отпускает край — но кадр остаётся. Он удивлённо смотрит | «О. Ты остался. Ты мне нравишься». |
| 40–48 с | Карточка с деталями; герой показывает на неё пальцем | «Сделай скриншот. Сейчас. Давай». |

**Почему цепляет.** Прямая команда в первые полсекунды и игра с механикой ленты. Идеально для Reels и Stories.
**Сложность.** Средняя: 3–4 ИИ-шота героя + анимация сдвига кадра.

## 10. «ФОТО ОЖИВАЕТ»

**Крючок (0–3 с).** Первые две секунды кажется, что вам прислали обычную фотографию героя:
статичную, чуть нелепую, с документа или из старого альбома. Потом герой на фото моргает,
смотрит по сторонам и говорит: «Ой. Уже записывает?»

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–2 с | Неподвижное фото героя в рамке, как в галерее телефона | Тишина |
| 2–5 с | Моргание, герой оглядывается | «Ой. Уже записывает?» |
| 5–15 с | Герой выбирается из рамки фото, рамка остаётся пустой | «Подожди, тут тесно». |
| 15–30 с | Герой «гуляет» по галерее телефона: заходит в соседние фото (море, кот, еда) и везде вешает гирлянды и шарики | «Слушай, есть дело. Я тут подумал: зачем ждать повода?» |
| 30–40 с | Все фото галереи превращаются в праздник, сетка мигает | «Вечеринка. Просто так». |
| 40–48 с | Герой возвращается в рамку, замирает, на нём появляется подпись с датой и адресом. Ещё одно моргание | «…я тут постою. Жду». |

**Почему цепляет.** Ожившая фотография — магия, которую ИИ делает лучше всего. Опирается на
готовый материал: фото героя.
**Сложность.** Средняя. Ключевой шот (оживление фото) почти гарантированно выходит хорошо.

## 11. «ГИПНОЗ»

**Крючок (0–3 с).** Чёрно-белая спираль крутится на весь экран, гипнотический голос:
«Смотри в центр. Не моргай. Ты становишься… очень… свободным… в субботу».

| Время | Кадр | Голос / текст |
|---|---|---|
| 0–5 с | Спираль, пульсирующий звук | «Смотри в центр. Не моргай…» |
| 5–15 с | В центре спирали проявляется лицо героя-гипнотизёра (ИИ: тюрбан, маятник с чипсиной) | «Ты слышишь только мой голос. Тебе не нужен повод». |
| 15–25 с | Маятник качается, на нём по очереди: дата, время, адрес | «Суббота… девятнадцать ноль-ноль… [адрес]…» |
| 25–35 с | Гипнотизёр сбивается: телефон звонит, маятник падает, чипсина ломается | «Так… на чём мы… ладно, просто приходи». |
| 35–40 с | Щелчок пальцами, спираль исчезает | «На счёт три ты проснёшься и ответишь „да“. Раз, два…» |
| 40–48 с | Карточка-«установка»: детали + «Ты уже согласился» | «Три». |

**Почему цепляет.** Спираль физически притягивает взгляд, а абсурдный гипнотизёр смешит контрастом.
**Сложность.** Низкая-средняя: спираль — графика, ИИ только для героя-гипнотизёра.

## Сравнение крючков (варианты 6–11)

| | Сила первых 2 с | Неожиданность | Сложность ИИ | Работает без звука |
|---|---|---|---|---|
| 6. Входящий звонок | ★★★ | ★★★ | ★ | ★★★ (интерфейс понятен) |
| 7. Видео сломалось | ★★★ | ★★★ | ★★ | ★★ |
| 8. «Как я сюда попал» | ★★★ | ★★ | ★★ | ★★ |
| 9. Не листай | ★★★ | ★★ | ★★ | ★★ (нужны субтитры) |
| 10. Фото оживает | ★★ | ★★★ | ★★ | ★★★ |
| 11. Гипноз | ★★ | ★★ | ★ | ★ (держится на голосе) |

**Рекомендация режиссёра по второй волне:** вариант 6 («Входящий видеозвонок»). Сильнейший
крючок: зритель буквально тянется нажать «принять». Он дешёвый и легко персонализируется (имя
героя в интерфейсе). Если хочется больше «вау» от ИИ — вариант 10 («Фото оживает»).
Сильная связка: **6 + 10**. Звонок принимается, а вместо видео — неподвижная фотография, которая оживает.

## Что нужно для реализации

1. Выбрать вариант (или комбинацию).
2. Имя героя (как его зовут друзья), дата, время, адрес, дресс-код, как ответить (RSVP).
3. 3–5 фото героя: анфас, хорошее освещение, без очков и других людей в кадре.
4. Голос: запишете финальную фразу сами или озвучим ИИ?
5. Пара внутренних шуток или имён друзей для персонализации.
