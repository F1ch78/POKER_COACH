# Покерный тренер для Android

Голосовой разбор раздач прямо на телефоне, компьютер не нужен. Это веб-приложение: оно ставится
на главный экран и открывается как обычное приложение, без адресной строки.

## Как установить (один раз, минут 10)

Приложению нужен адрес в интернете с https: без этого Android не даёт доступ к микрофону.
Бесплатно и проще всего сделать это через GitHub Pages. Шаги удобнее выполнять с компьютера.

1. Зарегистрируйтесь на **github.com** (бесплатно).
2. Справа вверху нажмите **+ → New repository**. Название, например, `poker-coach`,
   тип **Public**, затем **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file** и перетащите в окно
   **все файлы из этой папки** (index.html, app.js, иконки и т. д., без вложенных папок).
   Нажмите **Commit changes**.
4. Откройте **Settings → Pages**. В поле *Branch* выберите **main** и **/ (root)**, нажмите **Save**.
   Через 1–2 минуты там появится адрес вида `https://ваш-логин.github.io/poker-coach/`.
5. Откройте этот адрес на телефоне в **Google Chrome**, затем меню **⋮ → Добавить на главный экран**
   (или «Установить приложение»).
6. Запустите приложение с главного экрана и вставьте API-ключ Claude в настройках.
   Нажмите «Проверить связь», затем «Проверить голос».

API-ключ хранится только в памяти телефона. На GitHub он не попадает, поэтому по ссылке его никто не увидит.

## Как пользоваться

- **🎤** — нажмите и говорите. Нажмите ещё раз (■), когда закончите.
  После паузы в 3,5 секунды фраза отправится сама.
- Во время ответа тренера нажмите 🎤, чтобы перебить его и сказать своё.
- **🔁 Разговор** — после ответа тренера микрофон включается сам, и можно общаться без рук.
- **⌨ Текст** — печатать вопросы вместо голоса.
- **Карточка** показывает, что тренер понял: турнир, список раздач и текущую раздачу.
  Нажмите на раздачу, чтобы сделать её текущей. Ошибки можно поправить голосом.
- **Сессии** — все разборы сохраняются. По умолчанию открывается последний.
- **База** — добавьте свои .txt, .md и .pdf (книги, конспекты, чарты). Тренер опирается на них в ответах.

## Что нужно знать

- **Интернет обязателен.** Речь распознаёт сервис Google, встроенный в Chrome, а отвечает Claude.
  Если появляется ошибка «Нет связи с сервером Claude», скорее всего, нужен включённый VPN.
  Прокси можно указать в настройках.
- **Голос.** Используется голос синтеза речи Android. Если нет русского голоса:
  Настройки Android → Язык и ввод → Синтез речи → Google → установить русский.
- **Расчёты.** Эквити, пот-оддсы и EV пуша считаются на телефоне встроенным калькулятором.
  Нейросеть их не придумывает.
- **Модель.** Если модель из настроек стала недоступна, впишите актуальное название.
  `claude-haiku-4-5` дешевле и быстрее.

## Обновление

Замените файлы в репозитории на GitHub на новые версии. Приложение подтянет их само при следующем
запуске с интернетом. Сессии и база знаний на телефоне при этом сохранятся.
