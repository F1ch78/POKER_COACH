# Студия контента

Веб-приложение для производства роликов из сценария: документы → раскадровка → промпты для генераторов → картинки и видео → готовый фильм. Работает в браузере, без сервера и установки. Все данные лежат в этом браузере (IndexedDB).

## Запуск

1. Скачайте архив ветки ([zip](https://github.com/F1ch78/POKER_COACH/archive/refs/heads/claude/awesome-davinci-w8c10j.zip)) и распакуйте его.
2. В папке `content_studio` дважды щёлкните **`start-studio.bat`**. Откроется чёрное окно моста и сама студия по адресу `http://localhost:8787`.
3. Работайте в студии, а окно моста не закрывайте: в нём видно каждый запрос к ИИ.

Мост (`server.ps1`) работает на PowerShell, который уже есть в Windows, ставить ничего не нужно. Он делает то же, что Chatbox: передаёт запросы к ИИ-сервису с компьютера, поэтому запрет браузера (CORS) не мешает. Если Windows спросит про запуск файла из интернета, нажмите «Подробнее → Выполнить в любом случае».

Без моста можно открыть `index.html` прямо в Chrome. Всё будет работать, кроме прямых запросов к сервисам, которые не принимают запросы из браузера; для них есть режим «Через Chatbox».

**Перенос проекта.** Студия через мост (`http://localhost:8787`) и студия из файла (`index.html`) хранят проекты отдельно, и ключ тоже. Чтобы перенести проект, в старой студии нажмите «Монтаж → Бэкап с файлами», а в новой перетащите этот файл на «Материалы». Ключ впишите заново в ⚙.

## С чего начать: состав проекта

Проект может начинаться с любой стадии. При создании проекта (кнопка **+**) студия спрашивает, что уже есть: идея, библия мира, каст-библия, поэпизодный план, сценарий, шот-лист, картинки, видео, озвучка, музыка. Отметьте галочками, что есть, и сразу загрузите файлы (.md, .txt) или вставьте текст.

**Всё, что есть — переложить под студию.** Вверху окна создания можно загрузить разом все документы проекта в любом виде: сценарий, библию, раскадровку, промпты, заметки. Студия сохранит их как есть, а если стоит галочка «Переложить под студию через ИИ», помощник по этим материалам заполнит всё, чего в проекте ещё нет: паспорт и идею (жанр, формат, вертикальный кадр), стиль LOOK / STYLE / NEGATIVE, героев с тег-сетами и листами, плейты локаций, текст сцен с шотами, шот-лист с длительностями и героями в кадре, голоса (если есть реплики) и английские описания шотов. Материалы автора для него закон: нумерация сцен, кадры и хронометраж сохраняются. Нужен ключ в ⚙ или режим «Через Chatbox» (тогда каждый запрос студия покажет для копирования). Уже распознанное студией напрямую (каст-библия, сценарий в её формате) ИИ не переписывает.

По ответам студия выстраивает порядок работ (он виден внизу анкеты) и прячет лишнее:
- **есть сценарий** — работа начинается с «Материалов», а в «Разработке» остаются только недостающие шаги (например, шот-лист и голоса). Шаги, которые нужны лишь чтобы написать уже готовое (библия мира, план), свёрнуты как необязательные;
- **есть только идея** — первой идёт «Разработка»;
- **есть картинки и видео** — «Конвейер» скрыт; **есть озвучка** — скрыта «Озвучка».

Вкладки нумеруются в порядке работ. Скрытые разделы открываются кнопкой «…» справа от вкладок. Изменить состав проекта можно в любой момент кнопкой **🧭** в шапке.

Сценарий распознаётся и в оформлении шаблона: «СЦЕНА 1. МЕСТО - ВРЕМЯ» без решёток, «Тип:» и «Хронометраж:» без жирного, строки «Действие:».

## История действий

Справа узкая колонка «История»: все действия студии и ИИ в столбик, новые сверху, со временем. Огонёк у записи: **синий** — в очереди, **жёлтый** — выполняется, **зелёный** — готово, **красный** — ошибка или прервано. Перенос материалов сразу ставит в очередь все свои этапы, пакетная генерация — все шоты. Кнопка «›» сворачивает колонку в полоску с одним огоньком, «очистить» убирает завершённые записи.

## Как работать

0. **Разработка.** Если есть только идея — начните здесь: по шаблону «Но пасаран» помощник (или ваш чат по готовым запросам) напишет библию мира, каст-библию и плейты, поэпизодный план, текст сцен, шот-лист и голоса в формате студии. К идее можно приложить фото, видео и аудио. Там же — критика проекта от экспертов. Подробно — в разделе «Разработка» ниже.

1. **Материалы.** Перетащите документы в окно:
   - **сценарий** (`### СЦЕНА 5. РЕКА - СУМЕРКИ`, строки шотов `[КРУПНЫЙ] …`, реплики `ГЕРОЙ: …`, `ГЕРОЙ (V.O.): …`, `Сдвиг:`, `Хронометраж:`) разбирается на сцены и шоты; длительности подгоняются под хронометраж;
   - **каст-библия** (блоки кода под `**Имя**`, `**Имя — лист**`, `### Плейт …` с `SET:`, блоки `LOOK:`/`STYLE:`/`NEGATIVE:`) превращается в героев, локации и стиль;
   - **библия мира** и всё остальное хранится как справка для ИИ.

   Если в сценарии героя зовут иначе, чем в каст-библии (например, ЗОЛОТОГЛАЗЫЙ и Император), студия покажет это вверху: выберите героя из списка, и имя станет его псевдонимом.
2. **Раскадровка.** Здесь видны сцены и шоты. Можно поправить текст, длительность, тип кадра, отметить героев в кадре, выбрать локацию сцены.
   Кнопка **«ИИ: английские описания шотов»** переводит действие шотов в описания для генераторов (нужен ключ в ⚙, см. ниже). Без ключа описания можно вписать вручную.
   Промпт картинки = ракурс + описание кадра + тег-сеты героев + SET локации + LOOK/STYLE/NEGATIVE.
3. **Конвейер.** Шоты идут по очереди: скопируйте промпт, сгенерируйте картинку (или видео) в любом сервисе и вставьте результат через **Ctrl+V** или перетащите файл. Студия сама перейдёт к следующему пустому шоту. Рядом показаны референсы героев и локации, а в режиме видео ещё и кадр шота для image-to-video.
4. **Озвучка.** Реплики из сценария читаются русскими голосами (Piper) прямо на вашем компьютере, бесплатно и без ключей. Можно добавить свои голоса или подложить свою запись. Подробно — в разделе «Озвучка» ниже.
5. **Звук.** Саунд-дизайн: музыка по сценам, атмосфера сцен, звуковые эффекты в шотах и микшер. Подробно — в разделе «Звук» ниже.
6. **Монтаж.** Аниматик доступен сразу: шоты без картинок показываются карточками. По мере загрузки ассетов он превращается в фильм. Внизу лента таймлайна: золотым отмечено видео, зелёным картинки, серым пустые шоты.
   **«Записать видео»** собирает ролик (MP4 или WebM) с субтитрами, затемнениями, звуком из видео, озвучкой шотов и фоновой дорожкой. Запись идёт в реальном времени, поэтому вкладку нельзя сворачивать.

## Ключ для ИИ

Нажмите ⚙ справа вверху. Поля такие же, как у своего провайдера в Chatbox («OpenAI API Compatible»): API Key, API Host, API Path, модель.

- **Ключ CheapVibeCode** (`sk-cvc-…`): вставьте ключ, Host `https://ru.cheapvibecode.ru/v1` и формат OpenAI подставятся сами. Path можно оставить пустым или вписать `/chat/completions`, как в Chatbox.
- **Ключ Anthropic** (`sk-ant-…`): Host оставьте пустым.
- **Другой сервис**: перенесите Host, Path и модель из настроек Chatbox.

Нажмите **«Проверить связь»**: студия покажет адрес запроса, ответ модели и подгрузит список моделей в поле «Модель».

**Если в Chatbox ключ работает, а в студии «Нет связи».** Значит, сервис не принимает запросы из браузера (Chatbox — программа, на неё этот запрет не действует). Откройте студию через **`start-studio.bat`** — в ⚙ появится строка «✓ Студия открыта через мост». Если мост запустить нельзя, выберите режим **«Через Chatbox»**. При нажатии кнопки «ИИ» студия покажет готовый запрос: скопируйте его в Chatbox, а ответ вставьте обратно. Студия сама разберёт ответ и разложит описания по шотам. Это окно появится и само, если браузер не достучится до сервиса.

## Автоматическая генерация картинок

1. **Настройка.** ⚙ → раздел «Картинки» → выберите сервис:
   - «Тот же сервис и ключ, что для текста» — для CheapVibeCode и похожих шлюзов;
   - «Google Gemini — Nano Banana» с ключом `AIza…`;
   - другой OpenAI-совместимый сервис.
2. **Подбор.** Нажмите **«Подобрать автоматически»**. Студия перепробует модели и способы на тестовой картинке с яблоком, запомнит рабочий и подставит его в поля. Нажмите «Сохранить».

   **CheapVibeCode** работает через аккаунты ChatGPT. Модели картинок и Gemini из его списка отвечают «503: This model is not available through the connected ChatGPT accounts». Рисует сама модель GPT (та же, что для текста) встроенным инструментом через `/responses`, формат «GPT рисует сам». Поле «Модель» можно оставить пустым, тогда рисует модель текста.
3. **Генерация.**
   - Шот: кнопка «🎨 Сгенерировать» в раскадровке или в «Конвейере» (клавиша G).
   - Сцена: «🎨 Картинки сцены».
   - Весь фильм: «🎨 Все пустые» в «Конвейере» (картинки с выбранной сцены или всех сцен).
   Ход генерации и ошибки видны в полосе под шапкой, там же кнопка «Остановить».

Вместе с промптом студия отправляет референсы: лист каждого героя в кадре и плейт локации (их загружают на «Материалах»). Поэтому важно, чтобы у шота были отмечены верные герои. «ИИ: описать все шоты» не только пишет английские описания, но и отмечает, кто в кадре. Ручные отметки главнее.

**Ещё вариант.** Если картинка не понравилась, нажмите «🎨 ещё вариант». Прежняя картинка не пропадает: откройте кадр крупно и щёлкните по нужному варианту внизу, чтобы вернуть его.

## Видео

### Бесплатно, через любой сайт (motion16 и похожие)

У бесплатных видеосервисов обычно нет API, поэтому студия помогает работать с их сайтом:

1. Откройте студию через `start-studio.bat`, зайдите в «Конвейер» и переключитесь на «🎬 Видео».
2. Включите **«👀 подхватывать скачанное из «Загрузок»»**.
3. Для каждого шота:
   - нажмите «⧉ Кадр в буфер» и вставьте кадр на сайте генератора через Ctrl+V;
   - нажмите «⧉ Скопировать промпт» и вставьте промпт;
   - сгенерируйте видео и скачайте его.
4. Как только файл появится в папке «Загрузки», студия сама положит его в текущий шот и перейдёт к следующему.

**Длина промпта.** Сайты ограничивают промпт (motion16 — 2000 символов). Поле «лимит промпта» в «Конвейере» (и в ⚙ → «Видео») задаёт максимум, по умолчанию 2000. Студия укладывается в лимит по важности:
- ракурс, действие и реплика остаются всегда;
- описания героев, места и стиля сначала сокращаются, потом выбрасываются.

Если у шота есть картинка (её вставляют через «⧉ Кадр в буфер»), внешность героев и место в промпт не пишутся: они уже на кадре. Под промптом виден счётчик символов.

### Автоматически через API

⚙ → раздел «Видео» → выберите сервис:

- «Тот же сервис, что для текста» — если ваш шлюз умеет Sora (`/v1/videos`);
- OpenAI Sora, fal.ai, Replicate (модели Kling, Wan, Hailuo, Seedance) или Google Veo — со своим ключом.

Укажите модель (подсказки в выпадающем списке) и нажмите «Проверить видео»: студия сделает короткий тестовый ролик. Учтите, что у платных сервисов это спишет деньги.

После настройки работают кнопки:
- «🎬 Видео» у шота;
- «🎬 Видео сцены» в раскадровке;
- «🎬 Все без видео» в «Конвейере» (клавиша G — текущий шот).

Если у шота есть картинка, она уходит как первый кадр, и видео «оживляет» её. Ход генерации виден в полосе под шапкой. Прошлые варианты видео, как и картинок, можно вернуть в просмотре кадра.

## Озвучка

Работает, только когда студия открыта через **`start-studio.bat`**: голоса синтезирует программа Piper, а запускает её мост.

1. Откройте вкладку **«Озвучка»**. В блоке «Голоса героев» перечислены все, кто говорит в сценарии, и рассказчик, если в сценах есть строки `РАССКАЗЧИК:` или `НАРРАТОР:`.
2. Выберите каждому голос и скорость. Голоса: Дмитрий, Денис, Руслан (мужские) и Ирина (женский). Кнопка «▶ Проба» читает первую реплику героя.
3. Нажмите **«🎙 Озвучить всё, что без звука»** или «🎙 Озвучить» у отдельного шота.

Как это устроено:
- Реплики шота читаются по очереди с паузой между ними и сохраняются как звук шота (🔊). Закадровый текст рассказчика становится звуком сцены. Этот звук играет в «Монтаже» и попадает в записанное видео.
- Ремарки в скобках, например «(тихо)», не читаются.
- Если реплика длиннее шота, шот удлиняется (это можно отключить).
- Если после озвучки поменять текст реплики или голос героя, у шота появится «⚠ устарела», а кнопка «↻ Переозвучить изменённые» обновит такие шоты.
- Звук, загруженный вручную, не заменяется без спроса.

**Свои голоса.**
- **Голос Piper.** В блоке «Движок» нажмите «＋ Загрузить голос» и выберите сразу два файла: модель `.onnx` и настройки `.onnx.json`. Подойдёт любой голос Piper (из каталога голосов Piper или своя обученная модель). Голос появится в списке у каждого героя с пометкой «свой» и сохранится в папке `content_studio\tts\voices`. Если в модели несколько дикторов, читает первый.
- **Своя запись.** Кнопка «⬆ Своя запись» у шота или закадрового текста подкладывает готовый файл (mp3, wav, m4a), например реплику, записанную на телефон.

При первой озвучке мост один раз скачивает Piper (около 22 МБ, с github.com) и выбранный голос (около 60 МБ, с huggingface.co) в папку `content_studio\tts`. Ход загрузки виден в окне моста. Если голос не скачивается, проверьте доступ к huggingface.co: мост пробует и зеркало hf-mirror.com.

## Звук

Вкладка **«Звук»** — саунд-дизайн фильма. Работает и без моста.

1. **Библиотека звуков.** Нажмите «＋ Загрузить музыку и звуки» или перетащите файлы (mp3, wav, ogg, m4a) на страницу. Один файл можно использовать в разных местах.
2. **Музыка.** «＋ Музыкальный трек» → выберите файл и отрезок: с какой сцены и по какую. Если не задать «по», трек играет до своего конца. Ещё есть громкость, «по кругу» (трек повторяется до конца отрезка), плавное нарастание и затухание. Треки могут перекрываться.
3. **Атмосфера сцены.** Фоновый звук (дождь, ветер, город), который играет по кругу всю сцену с мягким входом и выходом.
4. **Эффекты в шотах.** У шота выберите «＋ эффект» и укажите, через сколько секунд от начала шота он звучит. Шоты со звуковыми пометками из сценария (`(звук: скрип двери)`) показаны сразу, и пометка подсвечена. Остальные шоты можно открыть галочкой «Показывать все шоты».
5. **Микшер.** Общая громкость голоса, музыки, атмосферы и эффектов. Галочка «Приглушать музыку, пока звучат реплики» плавно убирает музыку под голос.

Всё это звучит в «Монтаже» и попадает в записанное видео. Кнопка «▶ Смотреть» открывает сцену в «Монтаже». Фоновая дорожка из прежней версии студии сама превратится в музыкальный трек на весь фильм.

## Оценки и заметки

Под каждым готовым результатом можно поставить оценку и оставить заметку: под картинкой и видео шота, под звуком (озвучка или своя запись) и под саунд-дизайном сцены.

| Цвет | Что значит |
| --- | --- |
| серый | результата ещё нет |
| синий | результат есть, ждёт проверки |
| зелёный | ✓ готово |
| жёлтый | ✎ доработать |
| красный | ✕ переделать |

Выбранный элемент (шот, сцена, вкладка) выделяется белым.

Где ставить оценки:
- **Раскадровка.** У шота строка «Оценка» с метками по стадиям (картинка, видео, звук). Щелчок по метке открывает кнопки «Готово / Доработать / Переделать» и поле заметки. Левая полоса карточки окрашена по худшей оценке шота. В списке сцен слева видно, сколько шотов надо переделать (✕) и доработать (✎). Фильтры «Ждут проверки», «Доработать», «Переделать», «С заметками» показывают только такие шоты.
- **Просмотр кадра крупно** и **Конвейер.** Оценка стоит прямо под результатом. Номера шотов в списке конвейера окрашены так же.
- **Озвучка** — метка «Звук» у шота. **Звук** — метка «Саунд-дизайн» у сцены.
- **Монтаж.** Лента шотов окрашена по оценкам. Под лентой — оценка и заметка текущего шота, они меняются вместе с воспроизведением. Кнопка «📝 Список правок .md» скачивает всё, что надо доработать или переделать, вместе с заметками.

Когда вы заменяете файл (новая генерация, своя загрузка, возврат прошлого варианта), оценка сбрасывается в «ждёт проверки», а заметка остаётся, чтобы было видно, что просили поправить.

## Разработка

Вкладка **«Разработка»** ведёт от идеи до документов для производства по шаблону, которым сделана серия «Но пасаран».

**Идея.** Пара фраз о фильме или канале, жанр, визуальное направление, настроение, аудитория, язык фильмов, формат. Сюда же **📎 прикрепляются фото, видео и аудио** — референсы настроения, внешности героев, мест, света, музыки. Подпишите каждое вложение («холодный свет, туман», «так звучит главная тема»). Фото и три кадра из каждого видео уходят модели картинками (нужна модель, которая видит изображения), аудио — описанием. Внизу карточки — визуальные константы LOOK и NEGATIVE: они идут дословно в конец каждого промпта.

**Шаги** (каждый опирается на предыдущие):
1. **Библия мира** — шоураннер: мир, закон вселенной, фракции, сквозные герои, визуальный код, банк из 10 сюжетов, запреты.
2. **Каст-библия и плейты** — художник-постановщик: стиль канала, тег-сеты героев, листы персонажей, эталоны героев в сцене, плейты трёх главных локаций (SET и три кадра МАСТЕР / РАКУРС А / РАКУРС Б). «→ В материалы» — студия разберёт героев, локации и стиль.
3. **Поэпизодный план** — сценарист: сюжет из банка (впишите номер), три акта, тип каждой сцены (ЭКШЕН / ДИАЛОГ / НАРРАТОР-МОНТАЖ), хронометраж.
4. **Текст сцен** — порциями по три сцены: «сцены 1–3», потом «Дальше: сцены 4–6» и так до конца («🤖 Все до конца» пройдёт все порции сам). Ракурсы в квадратных скобках, РАКУРС А / Б, паузы, нарратор, сдвиг и «Хронометраж: по плану / по тексту». Под полем — сводка хронометража: сцены, где текст расходится с планом больше чем на 20%, подсвечены. «→ В материалы» — появятся сцены и шоты.
5. **Шот-лист** — режиссёр монтажа: карточки «03-01 · крупный · 5 сек» с плейтом, героями в кадре, действием, репликой, камерой и режимом СТИЛЛ→ВИДЕО / ТЕКСТ→ВИДЕО. **«→ В раскадровку»** перестраивает шоты сцен по карточкам: крупность, длительность, плейт, герои, реплика. Файлы остаются у шотов с теми же номерами.
6. **Голоса героев** — строка на героя (и нарратора) на английском. Она дословно идёт в реплики промптов «Шаблон: MOTION».

Промпты шага 6 шаблона (STILL для Nano Banana 2 и MOTION для Flow) студия собирает сама: выберите **«Шаблон: STILL»** и **«Шаблон: MOTION»** над шотами в раскадровке или в «Конвейере». В STILL — REFERENCES, FRAME, FOREGROUND, CHARACTER (тег-сет дословно), SET (дословно), LIGHT и LOOK / STYLE / NEGATIVE. В MOTION — CAMERA по крупности, PERFORMANCE по секундам, DIALOGUE с голосом героя, ATMOSPHERE, CONSISTENCY, AUDIO без музыки, AVOID.

Два способа работы:
- **🤖 Помощник в студии** пишет шаги сам через ИИ из ⚙ (или через Chatbox). Есть свободный чат с помощником по проекту.
- **📋 Гайд** — всё в одном своём чате (Claude, ChatGPT, DeepSeek). У каждого шага кнопка «⧉ Запрос для чата» с брифом, уже написанным и правилами шаблона; у текста сцен и шот-листа она сама подставляет номера следующей порции. Ответ вставьте в поле шага. «📄 Скачать гайд .md» — все шаги одним файлом.

**Критика: худсовет экспертов.** Выберите, что смотреть (идея и вложения, библия мира, каст-библия, план, текст сцен, раскадровка, готовые материалы с оценками) и кого спросить: продюсера, сценариста, режиссёра, оператора, художника-постановщика, художника по костюмам, монтажёра, звукорежиссёра, специалиста по ИИ-генерации, зрителя. Каждый ставит оценку из 10, называет сильные стороны, проблемы и что сделать.

## Под какую нейросеть промпт

Над шотами в раскадровке и в «Конвейере» есть выбор «🖼 промпт для» и «🎬 промпт для». Под каждым промптом написано, для какой нейросети он составлен и где ещё сработает.

| Картинки | Видео |
| --- | --- |
| Универсальный — GPT Image, Nano Banana, Flux | Универсальный — motion16 и похожие сайты, Hailuo, Wan |
| Шаблон: STILL — Nano Banana 2 с референсами | Шаблон: MOTION — Flow (Veo), стартовый кадр = STILL |
| GPT Image / Nano Banana — обычным языком, с форматом кадра | Kling — запреты отдельным «Negative prompt» в конце |
| Midjourney — одной строкой с `--ar`, `--style raw`, `--no` | Runway — только движение и камера, до 1000 символов |
| Stable Diffusion / Flux — через запятую и «Negative prompt» | Veo / Sora — с репликами по ролям и звуком |

Выбор хранится в проекте и действует на копирование промптов и экспорт «Промпты .md». В автоматической генерации через API используется универсальный промпт. Промпт, исправленный вручную, остаётся как есть.

## Код шота в промптах

Каждый скопированный промпт начинается с кода шота, как у файлов, например:

```
[S05_03]
Wide shot, 35mm lens. …
```

Так промпт легко узнать на сайте генератора и в истории запросов. Код добавляется везде, где промпт копируется: кнопки «⧉ Промпт картинки» и «⧉ Промпт видео», «⧉ Все промпты …» в раскадровке, поле промпта и копирование в «Конвейере». В видеопромпте код учитывается в лимите символов. В автоматическую генерацию через API код не попадает. Отключить его можно галочкой «код шота в начале промпта» в «Конвейере» или над шотами в раскадровке.

## Пакетная загрузка

Файлы с именами `S05_03.png`, `S05_03.mp4`, `S05_03.mp3` сами разложатся по шотам: сцена 5, шот 3. Код шота подписан на каждой карточке.

## Экспорт и перенос

- Промпты `.md`, шот-лист `.csv`, субтитры `.srt`.
- **Проект .json** — только тексты. **Бэкап с файлами** — один файл со всеми картинками и видео; его можно перетащить в студию на другом компьютере.
