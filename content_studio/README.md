# Студия контента

Веб-приложение для производства роликов из сценария: документы → раскадровка → промпты для генераторов → картинки и видео → готовый фильм. Работает в браузере, без сервера и установки. Все данные лежат в этом браузере (IndexedDB).

## Запуск

1. Скачайте архив ветки ([zip](https://github.com/F1ch78/POKER_COACH/archive/refs/heads/claude/bold-heisenberg-6149o0.zip)) и распакуйте его.
2. В папке `content_studio` дважды щёлкните **`start-studio.bat`**. Откроется чёрное окно моста и сама студия по адресу `http://localhost:8787`.
3. Работайте в студии, а окно моста не закрывайте: в нём видно каждый запрос к ИИ.

Мост (`server.ps1`) работает на PowerShell, который уже есть в Windows, ставить ничего не нужно. Он делает то же, что Chatbox: передаёт запросы к ИИ-сервису с компьютера, поэтому запрет браузера (CORS) не мешает. Если Windows спросит про запуск файла из интернета, нажмите «Подробнее → Выполнить в любом случае».

Без моста можно открыть `index.html` прямо в Chrome. Всё будет работать, кроме прямых запросов к сервисам, которые не принимают запросы из браузера; для них есть режим «Через Chatbox».

**Перенос проекта.** Студия через мост (`http://localhost:8787`) и студия из файла (`index.html`) хранят проекты отдельно, и ключ тоже. Чтобы перенести проект, в старой студии нажмите «Монтаж → Бэкап с файлами», а в новой перетащите этот файл на «Материалы». Ключ впишите заново в ⚙.

## Как работать

1. **Материалы.** Перетащите документы в окно:
   - **сценарий** (`### СЦЕНА 5. РЕКА - СУМЕРКИ`, строки шотов `[КРУПНЫЙ] …`, реплики `ГЕРОЙ: …`, `ГЕРОЙ (V.O.): …`, `Сдвиг:`, `Хронометраж:`) разбирается на сцены и шоты; длительности подгоняются под хронометраж;
   - **каст-библия** (блоки кода под `**Имя**`, `**Имя — лист**`, `### Плейт …` с `SET:`, блоки `LOOK:`/`STYLE:`/`NEGATIVE:`) превращается в героев, локации и стиль;
   - **библия мира** и всё остальное хранится как справка для ИИ.

   Если в сценарии героя зовут иначе, чем в каст-библии (например, ЗОЛОТОГЛАЗЫЙ и Император), студия покажет это вверху: выберите героя из списка, и имя станет его псевдонимом.
2. **Раскадровка.** Здесь видны сцены и шоты. Можно поправить текст, длительность, тип кадра, отметить героев в кадре, выбрать локацию сцены.
   Кнопка **«ИИ: английские описания шотов»** переводит действие шотов в описания для генераторов (нужен ключ в ⚙, см. ниже). Без ключа описания можно вписать вручную.
   Промпт картинки = ракурс + описание кадра + тег-сеты героев + SET локации + LOOK/STYLE/NEGATIVE.
3. **Конвейер.** Шоты идут по очереди: скопируйте промпт, сгенерируйте картинку (или видео) в любом сервисе и вставьте результат через **Ctrl+V** или перетащите файл. Студия сама перейдёт к следующему пустому шоту. Рядом показаны референсы героев и локации, а в режиме видео ещё и кадр шота для image-to-video.
4. **Монтаж.** Аниматик доступен сразу: шоты без картинок показываются карточками. По мере загрузки ассетов он превращается в фильм. Внизу лента таймлайна: золотым отмечено видео, зелёным картинки, серым пустые шоты.
   **«Записать видео»** собирает ролик (MP4 или WebM) с субтитрами, затемнениями, звуком из видео, озвучкой шотов и фоновой дорожкой. Запись идёт в реальном времени, поэтому вкладку нельзя сворачивать.

## Ключ для ИИ

Нажмите ⚙ справа вверху. Поля такие же, как у своего провайдера в Chatbox («OpenAI API Compatible»): API Key, API Host, API Path, модель.

- **Ключ CheapVibeCode** (`sk-cvc-…`): вставьте ключ, Host `https://ru.cheapvibecode.ru/v1` и формат OpenAI подставятся сами. Path можно оставить пустым или вписать `/chat/completions`, как в Chatbox.
- **Ключ Anthropic** (`sk-ant-…`): Host оставьте пустым.
- **Другой сервис**: перенесите Host, Path и модель из настроек Chatbox.

Нажмите **«Проверить связь»**: студия покажет адрес запроса, ответ модели и подгрузит список моделей в поле «Модель».

**Если в Chatbox ключ работает, а в студии «Нет связи».** Значит, сервис не принимает запросы из браузера (Chatbox — программа, на неё этот запрет не действует). Откройте студию через **`start-studio.bat`** — в ⚙ появится строка «✓ Студия открыта через мост». Если мост запустить нельзя, выберите режим **«Через Chatbox»**. При нажатии кнопки «ИИ» студия покажет готовый запрос: скопируйте его в Chatbox, а ответ вставьте обратно. Студия сама разберёт ответ и разложит описания по шотам. Это окно появится и само, если браузер не достучится до сервиса.

## Автоматическая генерация картинок

1. **Настройка.** ⚙ → раздел «Картинки» → выберите сервис:
   - «Тот же сервис и ключ, что для текста» — для CheapVibeCode и похожих шлюзов;
   - «Google Gemini — Nano Banana» с ключом `AIza…`;
   - другой OpenAI-совместимый сервис.
2. **Подбор.** Нажмите **«Подобрать автоматически»**. Студия перепробует модели и способы на тестовой картинке с яблоком, запомнит рабочий и подставит его в поля. Нажмите «Сохранить».

   **CheapVibeCode** работает через аккаунты ChatGPT. Модели картинок и Gemini из его списка отвечают «503: This model is not available through the connected ChatGPT accounts». Рисует сама модель GPT (та же, что для текста) встроенным инструментом через `/responses`, формат «GPT рисует сам». Поле «Модель» можно оставить пустым, тогда рисует модель текста.
3. **Генерация.**
   - Шот: кнопка «🎨 Сгенерировать» в раскадровке или в «Конвейере» (клавиша G).
   - Сцена: «🎨 Картинки сцены».
   - Весь фильм: «🎨 Все пустые» в «Конвейере» (картинки с выбранной сцены или всех сцен).
   Ход генерации и ошибки видны в полосе под шапкой, там же кнопка «Остановить».

Вместе с промптом студия отправляет референсы: лист каждого героя в кадре и плейт локации (их загружают на «Материалах»). Поэтому важно, чтобы у шота были отмечены верные герои. «ИИ: описать все шоты» не только пишет английские описания, но и отмечает, кто в кадре. Ручные отметки главнее.

**Ещё вариант.** Если картинка не понравилась, нажмите «🎨 ещё вариант». Прежняя картинка не пропадает: откройте кадр крупно и щёлкните по нужному варианту внизу, чтобы вернуть его.

## Пакетная загрузка

Файлы с именами `S05_03.png`, `S05_03.mp4`, `S05_03.mp3` сами разложатся по шотам: сцена 5, шот 3. Код шота подписан на каждой карточке.

## Горячие клавиши

| Где | Клавиша | Что делает |
| --- | --- | --- |
| Монтаж | Пробел | пуск и пауза |
| Монтаж | ← → | предыдущий или следующий шот |
| Конвейер | ← → | соседний шот |
| Конвейер | C | скопировать промпт |
| Конвейер, Раскадровка | Ctrl+V | вставить картинку или видео из буфера |
| Раскадровка | J / K | следующая или предыдущая сцена |

## Экспорт и перенос

- Промпты `.md`, шот-лист `.csv`, субтитры `.srt`.
- **Проект .json** — только тексты. **Бэкап с файлами** — один файл со всеми картинками и видео; его можно перетащить в студию на другом компьютере.
